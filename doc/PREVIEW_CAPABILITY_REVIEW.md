# 通用文件预览能力核查与改进记录

本记录只涉及 eap-fileview 的通用技术能力与回归候选，不包含使用方的实现、项目管理或业务数据。

## 已完成的通用改进

| 特性 | 已实现的能力 | 验证重点 |
| --- | --- | --- |
| XMind | URL 获取失败提示、错误数据识别、页面下拉控件修复 | 过期 URL、合法文件、页面交互 |
| 文件来源 | 二进制错误 MIME 拦截、短期 URL 日志脱敏 | HTML/JSON 错误响应、正常二进制响应 |
| CAD/3D | 保留合法文本型 CAD、glTF 与 DXF 文件预览 | ASCII STEP/IGES/DXF、glTF JSON |
| Office | 可选 Word 转 PDF 回退 SPI、有效 PDF 输出校验 | 转换失败、扩展缺席、加密文件 |
| 字体 | 可选 OOXML 字体诊断，默认关闭 | docx/docm、缺字体和异常输入 |

这些能力作为可选和通用改进，不要求某个文件存储系统的数据库、权限模型或专有 SDK。

## 后续候选（尚未实现）

- 特殊 PDF 的解析错误恢复、书签/目录兼容
- PDF 前端阅读模式、自适应缩放、图片 DPI 和水印显示问题
- 不同 Office 格式的修订与批注一致性；改变显示语义的处理应默认关闭
- 特殊 CAD/3D 文件的可替换转换器与转换结果接口
- FreeMarker 页面及静态文件加载在不同浏览器中的回归

候选不代表已经完成；优先复用当前 kkFileView 5.x 能力，有真实失败样本后再实施最小补丁与测试。

## 工程边界

- 支持授权 HTTP(S) 文件地址；不存储或重新定义使用方的账号、组织、权限、文件版本
- 扩展 SPI 为可选能力；商业插件、许可证及应用模型由使用方负责
- 同步上游安全/格式修复时，保持 Java 21 + Spring Boot 4.1 的发行基线
- 以可复现文件、针对性测试和实际预览输出作为完成证据
